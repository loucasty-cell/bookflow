# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer assessment |
| `needs-info` | `needs-info` | Awaiting more information |
| `ready-for-agent` | `ready-for-agent` | Specified for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Closed without planned work |
